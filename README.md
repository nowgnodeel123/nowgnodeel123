## About

Siemens Teamcenter 기반 PLM 시스템을 개발합니다.
조선·중공업 현장의 설계 데이터를 다루는 SI 프로젝트에서
**Active Workspace(AWC) 화면 커스터마이징**과 **Teamcenter SOA 연동 백엔드**를 함께 담당하고 있습니다.

- Spring Boot · MyBatis · Oracle 기반 서비스에서 Teamcenter SOA API를 연동해 PLM 데이터와 사내 시스템(ERP 등)을 잇는 구간을 개발합니다.
- AWC 선언형 프레임워크(ViewModel JSON / Service JS / HTML View)로 현업 요구사항에 맞는 화면과 커맨드를 구현합니다.
- 대용량 설계 데이터 마이그레이션을 수행하며 실제 운영 데이터의 정합성 문제를 다뤘습니다.

동서대학교 소프트웨어학과를 졸업하고 메가존클라우드 Java 개발자 양성 과정을 수료했습니다.
업무 밖에서는 Spring Boot / Next.js로 개인 프로젝트를 만들며 범용 웹 스택 감각을 유지하고 있습니다.
